FRANÇAIS · ORTHOGRAPHE GRAMMATICALE

L’accord du participe passé

Avec être, avec avoir, sans auxiliaire : une méthode simple pour ne plus se tromper.

Niveau 3ème · Enseignante : Tilla

1Rappel : le participe passé

Le participe passé est une forme du verbe : mangé, fini, pris, venu. Il s’écrit avec un auxiliaire (être ou avoir) ou tout seul. Pour bien l’accorder, nous allons d’abord regarder quel auxiliaire il y a.

Trois cas à connaître :
  1. Sans auxiliaire → il s’accorde comme un adjectif.
  2. Avec être → il s’accorde avec le sujet.
  3. Avec avoir → jamais avec le sujet ; avec le COD s’il est placé avant le verbe.

2Sans auxiliaire

Sans auxiliaire, le participe passé joue le rôle d’un adjectif. Il s’accorde en genre et en nombre avec le nom auquel il se rapporte.

PhraseAccord
Elle porte un pull acheté hier.masculin singulier
Elle porte une jupe achetée hier.féminin singulier
Elle porte des vêtements achetés hier.masculin pluriel
Elle porte des chaussures achetées hier.féminin pluriel
Les filles déçues pleurent. → « déçues » s’accorde avec « filles ».

3Avec l’auxiliaire ÊTRE

Le participe passé s’accorde toujours avec le sujet.

Verbes qui se conjuguent souvent avec être : aller, venir, arriver, partir, entrer, sortir, monter, descendre, naître, mourir, rester, tomber, retourner.

Paul est arrivé ce matin. (il → -é)
Julie est partie hier soir. (elle → -ie)
Les garçons sont montés. (ils → -és)
Lisa et Maria sont rentrées. (elles → -ées)
Attention : certains de ces verbes (monter, descendre, sortir…) peuvent aussi avoir un COD. Dans ce cas, ils se conjuguent avec avoir (voir plus bas).

4Avec l’auxiliaire AVOIR

Règle 1 : avec avoir, le participe passé ne s’accorde jamais avec le sujet.
Règle 2 : il s’accorde avec le COD seulement si le COD est placé avant le verbe.

Comment trouver le COD ? Nous posons la question « qui ? » ou « quoi ? » après le verbe.

CasAccord ?Exemple
Pas de CODNonIls ont bien ri.
COD après le verbeNonElle a mangé tous les bonbons.
COD avant le verbeOuiLes bonbons, elle les a tous mangés.
Les poubelles, il les a sorties.
Astuce : les pronoms le, la, l’, les et que placés devant le verbe sont souvent des COD. Cherchons ce qu’ils remplacent !

5Un même verbe avec être ou avoir

Les verbes sortir, monter, descendre changent d’auxiliaire selon la phrase.

Avec ÊTRE (pas de COD)Avec AVOIR (il y a un COD)
Mes sœurs sont sorties.Elles ont sorti les albums.
Les albums qu’elles ont sortis.
Mes cousins sont montés au grenier.Ils ont monté une malle.
La malle qu’ils ont montée.

6Cas particuliers

  1. Verbes impersonnels : pas d’accord. Quelle chaleur il a fait ! / Quelle patience il a fallu !
  2. « fait » + infinitif : pas d’accord. Ma voiture était cassée, je l’ai fait réparer.
  3. Participe + infinitif : nous regardons si le COD fait l’action de l’infinitif.
    • Oui → accord : Les enfants que j’ai entendus chanter (les enfants chantent).
    • Non → pas d’accord : Les chansons que j’ai entendu chanter (les chansons ne chantent pas).
  4. Le pronom « en » : pas d’accord. Des pommes, j’en ai mangé. / Des films, j’en ai vu beaucoup.

7Les verbes pronominaux

Ce sont les verbes précédés d’un pronom réfléchi : se laver, se souvenir, s’absenter…

TypeRègleExemples
Essentiellement pronominauxAccord avec le sujetElles s’étaient absentées.
Ils se sont insurgés.
Occasionnellement pronominaux, « se » = CODAccord avec le COD s’il est avantElle s’est lavée. (se = elle)
COD placé après, ou « se » = COIPas d’accordElle s’est lavé les mains.
Elles se sont parlé.
Méthode : 1) Qui ? quoi ? → trouver le COD. 2) Où est-il placé ? Avant → accord. Après → pas d’accord.
À retenir absolument
  1. Être → accord avec le sujet.
  2. Avoir → jamais avec le sujet ; accord avec le COD placé avant.
  3. Sans auxiliaire → accord avec le nom, comme un adjectif.

8Résumé visuel

Exercice 1 — Accords simples

Consigne : recopie chaque phrase en accordant le participe passé entre parenthèses si nécessaire. S’il est déjà correct, laisse-le tel quel.

Exemple : Mes sœurs sont (arrivé). Elles ont (apporté) un album.
Réponse : Mes sœurs sont arrivées. Elles ont apporté un album.
  1. Ma grand-mère est (né) dans un petit village.
  2. Mes parents ont (gardé) mes premiers dessins.
  3. Mes cousines sont (venu) pendant les vacances.
  4. Ma sœur a (raconté) son premier souvenir.
  5. Les garçons sont (parti) après le déjeuner.
  6. Nous avons (regardé) les photographies de famille.
Voir la correction

née ; gardé ; venues ; raconté ; partis ; regardé

Exercice 2 — Souvenirs d’enfance
  1. Les vacances sont (terminé) depuis une semaine.
  2. Ma sœur a (retrouvé) son ancien journal intime.
  3. Mon frère et mon père sont (rentré) au village.
  4. Nous avons (passé) la journée chez nos grands-parents.
  5. Ma mère est (resté) dans le jardin.
  6. Mes cousines ont (écrit) leurs souvenirs dans un cahier.
  7. Les lettres sont (tombé) derrière le bureau.
  8. J’ai (rangé) les albums dans une boîte.
Voir la correction

terminées ; retrouvé ; rentrés ; passé ; restée ; écrit ; tombées ; rangé

Exercice 3 — Attention au COD
  1. Les photographies que j’ai (retrouvé) étaient anciennes.
  2. Ma sœur est (arrivé) pendant ma lecture.
  3. Nous avons (ouvert) la boîte à souvenirs.
  4. Les lettres sont (resté) dans le tiroir.
  5. Ces histoires, ma grand-mère les a souvent (raconté).
  6. Mes cousins sont (allé) dans notre ancienne école.
  7. La page que tu as (lu) raconte mon enfance.
  8. Elles ont (conservé) leurs journaux intimes.
Voir la correction

retrouvées ; arrivée ; ouvert ; restées ; racontées ; allés ; lue ; conservé

Exercice 4 — Un même verbe avec être ou avoir
  1. Mes sœurs sont (sorti) de leur chambre.
  2. Elles ont (sorti) les albums du placard.
  3. Les albums qu’elles ont (sorti) sont abîmés.
  4. Mes cousins sont (monté) au grenier.
  5. Ils ont (monté) une vieille malle dans leur chambre.
  6. La malle qu’ils ont (monté) appartenait à notre grand-père.
  7. Ma mère est (descendu) à la cave.
  8. Elle a (descendu) les cartons de souvenirs.
Voir la correction

sorties ; sorti ; sortis ; montés ; monté ; montée ; descendue ; descendu

Exercice 5 — Un texte de journal intime

La narratrice est une fille prénommée Léa. Accorde les participes passés entre parenthèses.

Cher journal,

Aujourd’hui, ma sœur et moi sommes (retourné) dans la maison de notre enfance. Nos parents ont (préparé) cette visite en secret. Nous sommes (entré) toutes les deux dans notre ancienne chambre. J’ai (retrouvé) une boîte que j’avais (caché) sous mon lit. Les lettres que j’avais (gardé) étaient toujours à l’intérieur. Ma sœur est (resté) près de moi quand je les ai (relu).

Puis nos parents sont (arrivé). Ensemble, nous avons (regardé) les photographies que notre grand-mère avait (pris). Ma sœur et moi sommes (reparti) avec la boîte. Cette journée a (réveillé) des souvenirs que nous avions presque (oublié).
Voir la correction

Cher journal,

Aujourd’hui, ma sœur et moi sommes retournées dans la maison de notre enfance. Nos parents ont préparé cette visite en secret. Nous sommes entrées toutes les deux dans notre ancienne chambre. J’ai retrouvé une boîte que j’avais cachée sous mon lit. Les lettres que j’avais gardées étaient toujours à l’intérieur. Ma sœur est restée près de moi quand je les ai relues.

Puis nos parents sont arrivés. Ensemble, nous avons regardé les photographies que notre grand-mère avait prises. Ma sœur et moi sommes reparties avec la boîte. Cette journée a réveillé des souvenirs que nous avions presque oubliés.

Quiz final
  1. Mes amies sont (venu) hier.
  2. Les fleurs que j’ai (acheté) sont belles.
  3. Elle a (mangé) les gâteaux.
  4. Elles se sont (parlé).
Voir la correction
  1. venues (être → accord avec le sujet « amies »)
  2. achetées (COD « que » = les fleurs, placé avant le verbe)
  3. mangé (le COD « les gâteaux » est après le verbe)
  4. parlé (« se » est un COI : on parle à quelqu’un, pas d’accord)
